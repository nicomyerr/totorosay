## Usage

Open your favourite Terminal and type:

```bash
totorosay Hello world!
```

And Totoro says `Hello world!`.

Use the `-b` or `--big` flag to use **big** Totoro:

![totorosay example](./docs/totorosay-big-hello-world.png)
